# TrendEttic – E-commerce Website

TrendEttic is a responsive **frontend e-commerce website** built using **HTML, CSS, and JavaScript**.  
The project focuses on clean UI design, product browsing, and basic cart interactions using client-side logic.

---

## 🚀 Features
- Responsive and modern user interface  
- Product listing and product detail sections  
- Dynamic cart functionality using JavaScript  
- Client-side interactivity with DOM manipulation  
- Clean layout and reusable UI components  

---

## 🛠️ Technologies Used
- **HTML5** – Structure and content  
- **CSS3** – Styling, layout, responsiveness  
- **JavaScript (ES6)** – Interactivity and logic  

---

## 📂 Project Type
**Frontend Web Development Project**
